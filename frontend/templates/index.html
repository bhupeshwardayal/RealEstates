Document Abstract

This document defines the complete functional and non-functional requirements, architectural blueprints, data models, and verification protocols for the AI-Powered Real Estate Advisor & Property Matcher. The system leverages modern Retrieval-Augmented Generation (RAG) and dense vector search to replace traditional rigid property filters with an intelligent conversational advisor capable of evaluating complex natural language constraints, calculating financial projections (e.g., loan amortization, EMI), and matching real estate assets with high precision and zero hallucinations.

1. Introduction & Definitions

The purpose of this document is to specify the technical requirements for an intelligent conversational property search engine.

Term Definition
RAG Retrieval-Augmented Generation: Grounding LLM responses on verified catalog retrieval.
FAISS Facebook AI Similarity Search: Low-latency sub-50ms vector clustering & retrieval.
EMI Equated Monthly Installment calculated with precise decimal mathematics.
Hallucination Synthetically generated false claims. Mitigated to 0% via strict prompt grounding.

2. Architecture & User Personas

Presentation Tier FastAPI Jinja2 + Tailwind CSS bright aesthetic responsive UI with dynamic sliders and modal drawers.
Application Tier Intent extraction, LangChain RAG pipeline, conversational memory, and decimal financial formula engine.
Data Tier FAISS IndexFlatIP dense vector store + SQLAlchemy PostgreSQL/SQLite relational property database.

3. Specific Functional Requirements (FR)

Module 1 (Data Ingestion): FR-1.1 Data Normalization, FR-1.2 Vector Embeddings Generation, FR-1.3 FAISS IndexFlatIP Index Persistence.

Module 2 (Query Processing): FR-2.1 Intent Extraction (budget Lakhs/Cr, min BHK, locality, amenities), FR-2.2 Conversational Memory.

Module 3 (Retrieval & Grounding): FR-3.1 Semantic Search Retrieval (Top-K=4), FR-3.2 Grounded Prompt Injection, FR-3.3 Fallback Handling.

Module 4 (Financial Engine): FR-4.1 Deterministic monthly loan EMI calculation ($E = P \cdot r \cdot \frac{(1+r)^n}{(1+r)^n - 1}$), FR-4.2 Gross Rental Yield ($\frac{\text{Annual Rent}}{\text{Price}} \times 100$).

4. Relational Schema & Vector Format

CREATE TABLE properties (

5. Non-Functional Requirements

• Performance: Sub-50ms vector search across property catalog.
• Accuracy: 0% hallucination rate on verified relational records with exact decimal math.
